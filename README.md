# Aurea Systems — Landing Page

Landing page editorial premium para **Aurea Systems**, sistema de captación con IA para clínicas de medicina estética facial.

## Stack

- **HTML5** estático (single file `index.html`)
- **Sistema de diseño:** Atelier Zero (paper + ink + coral)
- **Tipografías:** Playfair Display, Inter Tight, Inter, JetBrains Mono
- **Sin dependencias JS externas** — todo inlineado.

## Estructura

```
open-design-landing/
├── index.html              # Landing principal (single page)
├── inputs.json             # Esquema de contenidos (datos editables)
├── brand-spec.md           # Especificación de marca
├── assets/                 # Imágenes y SVGs editoriales
├── moyfyu7d-logo-aurea-systems-_22a_22.png
├── moyjak0v-video_landing.mp4
└── ESTRATEGIA-MEJORAS.md   # Análisis competitivo y roadmap (V2)
```

## Secciones

1. Hero — promesa + 4 fases del sistema
2. Problema — el agujero entre formulario y camilla
3. Sistema (4 fases conectadas)
4. Módulos operativos (5 frentes activos)
5. Método de implantación
6. Experiencias clave (Ana IA + Creative Studio)
7. Testimoniales y prueba social
8. Garantía + CTA final
9. Footer

## Despliegue

Es una landing estática. Cualquier hosting de archivos estáticos funciona:

- Vercel / Netlify (drop & deploy)
- GitHub Pages (Settings → Pages → branch `main`)
- Cloudflare Pages
